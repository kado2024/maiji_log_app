# おなじ時刻 サポート

## よくある質問

**決めた時刻以外に撮れません。**
仕様です。撮影できるのは定点時刻の15分前から45分後まで、1日1回です。記録をすべて「おなじ時刻」にそろえるためです。

**前回と同じ構図で撮るには？**
撮影画面の「前回と重ねる」をオンにすると、前回のコマが半透明で重なります。スライダーで濃さを変えられます。

**書き出した動画はどこにありますか？**
書き出し後に「写真に保存」を選ぶと「写真」アプリに保存されます。「共有」からほかのアプリに送ることもできます。

**カメラが起動しません。**
「設定」アプリ → おなじ時刻 で、カメラとマイクをオンにしてください。

**通知が来ません。**
アプリの設定で「定点時刻に知らせる」をオンにし、「設定」アプリ → おなじ時刻 → 通知 が許可されているか確認してください。

**機種変更でデータは引き継げますか？**
動画はiPhoneの中だけに保存されます。iPhoneのバックアップ（iCloudバックアップなど）から復元した場合は引き継がれます。
