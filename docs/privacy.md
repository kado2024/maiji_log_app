# 毎時ログ プライバシーポリシー

最終更新日：2026年11月3日

## 1. 収集する情報
毎時ログ（以下「本アプリ」）は、利用者の個人情報を収集しません。アカウント登録はなく、広告や行動追跡（トラッキング）のための仕組みも含まれていません。

## 2. カメラとマイク
本アプリは、2秒の動画を撮影するためにカメラとマイクを使います。撮影した動画とサムネイル画像は、利用者のiPhoneの中（本アプリ専用の保存領域）だけに保存され、外部のサーバーへ送信されることはありません。

## 3. 通知
利用者が設定でオンにした場合に限り、毎時00分のお知らせをiPhone内で予約して表示します。通知の内容が外部に送信されることはありません。

## 4. データの削除
本アプリの「設定」→「すべてのコマを削除」、または本アプリをiPhoneから削除することで、保存されたすべてのデータが削除されます。

## 5. 第三者への提供
本アプリはデータを収集しないため、第三者に提供することもありません。
