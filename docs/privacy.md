# おなじ時刻 プライバシーポリシー

最終更新日：2026年11月9日

## 1. 収集する情報
おなじ時刻（以下「本アプリ」）は、利用者の個人情報を収集しません。アカウント登録はなく、広告や行動追跡（トラッキング）のための仕組みも含まれていません。

## 2. カメラとマイク
本アプリは、毎日決めた時刻に2秒の動画を撮影するためにカメラとマイクを使います。撮影した動画と、構図合わせ用の静止画は、利用者のiPhoneの中（本アプリ専用の保存領域）だけに保存され、外部のサーバーへ送信されることはありません。

## 3. 写真ライブラリへの保存
利用者が「写真に保存」を選んだときに限り、書き出した動画を「写真」に追加します（追加のみの許可を使い、既存の写真を読み取ることはありません）。「共有」を選んだ場合は、利用者が選んだ共有先に動画が渡されます。

## 4. 通知
利用者が設定でオンにした場合に限り、決めた定点時刻のお知らせをiPhone内で予約して表示します。通知の内容が外部に送信されることはありません。

## 5. データの削除
本アプリの「設定」→「撮影した動画をすべて削除」、定点時刻の削除、または本アプリをiPhoneから削除することで、保存されたデータが削除されます。

## 6. 第三者への提供
本アプリはデータを収集しないため、第三者に提供することもありません。
